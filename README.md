# wakey — uptime monitor

Open source uptime monitor: checki HTTP/TCP/ping/heartbeat, agenci w sieciach prywatnych, alerty,
incydenty i publiczne status pages. Self-host bez zewnętrznych usług albo chmura w UE.

Stan: dokumentacja i research przed etapem 0, bez kodu.
